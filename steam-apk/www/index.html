🔑 Steam Web API kulcs
Hogyan kapok kulcsot? (ingyenes, 1 perc)
  1. Nyisd meg: steamcommunity.com/dev/apikey és lépj be.
  2. A „Domain Name” mezőbe írj bármit, pl. localhost, fogadd el a feltételeket, és nyomd meg a „Register” gombot.
  3. Másold ide a megjelenő Key értékét.
  4. A profilodon legyen nyilvános a játéklista: Profil szerkesztése → Adatvédelmi beállítások → Játékrészletek: Nyilvános.

A kulcs csak ezen a telefonon tárolódik, és csak a Steam szervereihez megy.

🏷️ Műfajok a Steam boltból

A műfajokat játékonként kell lekérni, a Steam lassítja a túl sűrű kérést, ezért ez nagy könyvtárnál pár percig tart. Közben nyugodtan használd az appot.

💾 Rendezés mentése / visszatöltése

A mentőkódban benne van minden állapot, értékelés, jegyzet és gyűjtemény (az API kulcs nincs). Új telefonon ide illesztve visszakapod.
